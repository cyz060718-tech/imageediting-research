# 精简范围

本仓库从现有 debug_improved 改进版建立，原项目没有删除或覆盖。

保留当前算法代码、全部现有回归检查、常用模型下载及实验工具、140 张图片与参考掩码、数据来源记录、最终 PPT 和 Word 文档、少量开发证据。

不纳入两个虚拟环境、模型权重、源码备份、原版与改进版重复目录、完整推理输出及候选、大型源标注缓存、历史调参脚本、文档构建依赖、渲染图片和草稿。这些文件仍在原项目中保留。

为独立部署作了两处路径调整：默认模型目录改为仓库内 models；高级模型目录支持 IMAGE_EDIT_EXTRA_MODEL_DIR。补齐基础模型下载脚本、依赖版本和通用启动入口。编辑算法及既有参数保持不变。

完整实验溯源仍以原项目中的逐例 record.json、候选和历史记录为准；仓库中的检查图不能替代完整原始实验材料。
